# Asset Kenney (CC0)

Modelli 3D di [Kenney](https://kenney.nl), rilasciati con licenza
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) (pubblico dominio).
Presi dagli Starter Kit ufficiali su GitHub (KenneyNL): 3D Platformer, City Builder,
Basic Scene (Mini Arena) e Racing. Sono segnaposto: verranno sostituiti man mano
con modelli originali di EmeraldQuest.
